# api-errors Specification

## Purpose

Описывает единый JSON-конверт ошибок API, по которому клиенты и frontend
различают машинный код и понятный пользователю текст.

## Requirements

### Requirement: Единый конверт ошибок

Любой ответ с ошибкой SHALL иметь тело `{code, message}`, где `code` —
стабильный машинный идентификатор, а `message` — текст на русском.

#### Scenario: Ожидаемая ошибка бизнес-логики
- **WHEN** операция завершается ошибкой с известным кодом
- **THEN** ответ содержит этот код и русское сообщение

#### Scenario: Ошибка валидации
- **WHEN** тело запроса не проходит валидацию
- **THEN** ответ 422 содержит `VALIDATION_ERROR` и перечень полей

#### Scenario: Необработанное исключение
- **WHEN** обработчик падает с непредвиденным исключением
- **THEN** ответ 500 содержит `INTERNAL_ERROR` и русское сообщение без стека и деталей реализации

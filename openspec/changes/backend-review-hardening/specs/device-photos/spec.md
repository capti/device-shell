# Spec Delta

## MODIFIED Requirements

### Requirement: Формат и размер файла

Система SHALL принимать только форматы jpeg, png и webp, определяемые по
содержимому файла, размером не более 10 МБ; иначе отвечать 422 и не сохранять
файл. Система SHALL отклонять с 422 изображения с чрезмерным числом пикселей,
а также пачки, количество или суммарный объём которых превышает лимит, не читая
всё содержимое запроса в память.

#### Scenario: Недопустимый формат
- **WHEN** загружают файл другого формата (например, GIF)
- **THEN** система отвечает 422 и файл не сохраняется

#### Scenario: Файл больше лимита
- **WHEN** размер файла превышает 10 МБ
- **THEN** система отвечает 422 и файл не сохраняется

#### Scenario: Изображение с чрезмерным числом пикселей
- **WHEN** загружают небольшой по объёму файл, содержащий изображение с числом
  пикселей выше допустимого предела
- **THEN** система отвечает 422 с кодом `UNSUPPORTED_FORMAT`, файл не сохраняется,
  а обработчик не завершается аварийно

#### Scenario: Слишком много файлов в запросе
- **WHEN** один запрос содержит больше файлов, чем допустимо для устройства
- **THEN** система отвечает 422 и не сохраняет ни один файл

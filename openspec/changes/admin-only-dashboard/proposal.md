# Proposal

## Why

Дашборд (`/dashboard`: семь счётчиков, топ просрочек, три графика) сейчас доступен
любому аутентифицированному пользователю — обычный сотрудник видит сводку по всему
парку устройств и просрочкам всей команды. Требуется разделение: дашборд — только
для роли admin, роль user дашборд не видит и не имеет к нему доступа.

## What Changes

- **Backend**: `GET /dashboard/stats` и `GET /dashboard/charts` переходят с
  `get_current_user` на `require_admin` — роль user получает `403 FORBIDDEN`
  (`Недостаточно прав`).
- **Frontend — навигация**: пункт «Дашборд» в боковом меню показывается только
  роли admin.
- **Frontend — маршрут**: пользователь с ролью user, открывший `/dashboard`
  напрямую по URL, редиректится на `/devices` (в том числе после входа без
  целевого маршрута и через catch-all маршрут `*`).
- **Спеки**: уточняются требования ролей и оболочки; агрегаты графиков
  дашборда становятся admin-only.

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `access-control`: ADDED требование «Доступ к дашборду» — эндпоинты
  `/dashboard/stats` и `/dashboard/charts` отдают данные только роли admin,
  для роли user — 403.
- `frontend-shell`: MODIFIED требования «Оболочка и навигация» (пункт
  «Дашборд» только для admin), «Дашборд со счётчиками и просрочками» и
  «Графики на дашборде» (открывает только admin; user получает редирект на
  `/devices`).
- `reports-export`: MODIFIED требование «Агрегаты для графиков дашборда» —
  `GET /dashboard/charts` отдаётся роли admin, а не любому аутентифицированному
  пользователю.

## Impact

- `backend/app/api/reports.py` — два эндпоинта дашборда на `require_admin`.
- `backend/tests/test_reports.py` — тесты 403 для user и 200 для admin.
- `frontend/src/components/AppShell.tsx` — фильтрация `NAV_ITEMS` по роли.
- `frontend/src/routes.tsx` — проверка роли в `ProtectedLayout`/маршруте
  `/dashboard` с редиректом на `/devices`.
- Спеки `access-control`, `frontend-shell`, `reports-export`.

## Не входит в изменение

- Страница `/reports` и Excel-экспорт остаются доступны любому
  аутентифицированному пользователю (требование «Доступ к отчётам» не меняется).
- Счётчики и графики не меняются по составу и формуле просрочки.
- База данных, миграции, инварианты — без изменений.
- Права `user` на свои/держащиеся устройства, справочник людей, уведомления —
  без изменений.

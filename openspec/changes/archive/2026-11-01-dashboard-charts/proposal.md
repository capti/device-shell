# Proposal

## Why

Дашборд сейчас — это только семь счётчиков и таблица топ-5 просрочек: он
отвечает на вопрос «сколько», но не показывает динамику. Не видно, растёт ли
оборот парка, копятся ли возвраты, и насколько глубока просрочка — «5
устройств просрочено» не отличает неделю от месяца. Для ежедневного контроля
парка телефонов нужны графики, отвечающие на эти вопросы одним взглядом.

## What Changes

- **Backend**: новый эндпоинт `GET /dashboard/charts` (только для
  аутентифицированных, как `/dashboard/stats`) отдаёт агрегаты для двух
  графиков:
  - `turnover` — выдачи и возвраты по месяцам за последние 12 месяцев
    (включая текущий): `month` (YYYY-MM), `checked_out`, `returned`;
  - `overdue_buckets` — просроченные устройства по корзинам длительности
    1–7, 8–14, 15–30, 31+ дней. Просрочка считается той же единственной
    формулой из `services/device_state` (инвариант 6).
- **Frontend**: на дашборде добавляются три графика (`@mantine/charts`,
  новая зависимость):
  - **Выдачи и возвраты** — bar-график по месяцам из `turnover`;
  - **Состояние парка** — donut из уже готовых счётчиков
    `GET /dashboard/stats` (новые данные не нужны);
  - **Возраст просрочки** — bar-график по корзинам из `overdue_buckets`.
- Счётчики, топ просрочек и их поведение не меняются.

### Не входит

- «Кто держит больше всего» и «Парк по моделям» — отложены, могут прийти
  позже тем же эндпоинтом.
- Backend-расчёты для donut: он строится из существующих счётчиков.
- Изменение формулы просрочки или поведения счётчиков.

## Capabilities

### Modified Capabilities

- `reports-export`: ADDED — агрегаты для графиков дашборда (эндпоинт
  `GET /dashboard/charts`).
- `frontend-shell`: ADDED — три графика на дашборде и их состояния.

## Impact

- Новые: `backend/app/schemas/reports.py` (схема ответа графиков),
  `frontend/src/lib/charts.ts` (или аналог — маппинг данных графиков).
- Правки: `backend/app/api/reports.py`, `backend/app/services/reports.py`,
  `frontend/src/api/reports.ts`, `frontend/src/pages/DashboardPage.tsx`,
  `frontend/package.json` (+`@mantine/charts`).
- Тесты: `backend/tests/` — агрегаты по месяцам, корзины просрочки, доступ.

# Design

## Context

`GET /dashboard/stats` (`services/reports.py: dashboard_stats`) уже считает
семь счётчиков одним проходом по `device_state_query()` и топ-5 просрочек.
Для графиков нужны две новые агрегации: выдачи/возвраты по месяцам (из
`checkouts.taken_at`/`returned_at`) и возраст просрочки (из той же
state-запросы — единая формула, инвариант 6). Дашборд рендерит
`DashboardPage.tsx`; библиотеки графиков во фронте нет.

## Goals / Non-Goals

**Goals:**

- Три графика на дашборде, отвечающие на вопросы ежедневного контроля:
  оборот парка, его состояние, глубина просрочки.
- Один новый эндпоинт агрегатов; donut — из существующих счётчиков.
- Графики не ломают дашборд при ошибке и на мобильной вёрстке.

**Non-Goals:**

- Интерактивные фильтры/дрель-даун по графикам.
- Графики на странице отчётов.
- История состояний (снимки счётчиков в прошлом) — данных нет.

## Decisions

1. **Один эндпоинт `GET /dashboard/charts`** вместо отдельных под
   каждый график: обе агрегаты дёшевы, фронт ждёт один запрос, контракт
   один. Donut в него не входит — ему хватает готовых счётчиков.

2. **Месяцы — последние 12, включая текущий**, формат `YYYY-MM`
   (локальное время `now_local`, не UTC — иначе границы месяцев сдвинутся).
   Возвраты учитываются по дате возврата независимо от даты выдачи:
   телефон, выданный в сентябре и возвращённый в октябре, даёт +1 в каждый
   из месяцев. Месяцы без событий присутствуют с нулями — фронт не достраивает
   шкалу.

3. **Корзины просрочки 1–7, 8–14, 15–30, 31+** — полные дни через
   `days_overdue` из `services/reports` (та же функция, что в Excel и
   топ-тайле). Считаются по активным выдачам с `holder != owner` из
   `device_state_query` — не пересчитываем формулу на месте.

4. **`@mantine/charts` (Recharts)** — единственная графическая зависимость,
   следует стилям Mantine без доп. темизации. Два вида: `BarChart`
   (динамика и корзины) и `DonutChart` (состояние). Цвета — палитра Mantine:
   выдачи/возвраты — `blue`/`green`, donut — пять статусных цветов.

5. **Графики — отдельным useQuery**, не в общем запросе дашборда: ошибка
   `charts` не должна ронять счётчики и таблицу (сценарий спеки). Блок
   ошибки — локальный `Alert` под заголовком раздела.

6. **Пустое состояние**: если за 12 месяцев нет ни выдач, ни возвратов —
   текст-заглушка вместо графика (спека требует не пустой прямоугольник).
   Donut и корзины всегда имеют данные (счётчиков нулевых не бывает:
   `with_owners` ≥ 0, корзины с нулями валидны).

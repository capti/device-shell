# Design

## Context

Экспорт записывает строки в листы через `openpyxl`; присваивание строки,
начинающейся с `=`, автоматически создаёт ячейку формулы. Сессии хранятся
отдельными строками в таблице `sessions`, а установка нового хеша пароля сейчас
не затрагивает эти строки. Требования описаны в delta-спеках `reports-export`,
`access-control` и `user-management`.

## Goals / Non-Goals

**Goals:**

- Гарантировать текстовый тип для строковых данных во всех листах экспорта.
- Атомарно обновлять пароль, уведомление и набор действующих сессий.
- Сохранить сессию, которой пользователь подтвердил самостоятельную смену
  пароля, и завершить остальные.

**Non-Goals:**

- Менять схему БД, формат отчёта, механизм cookie или срок действия сессий.
- Добавлять общий интерфейс управления сессиями.

## Decisions

- После добавления каждой строки экспорта все её строковые ячейки явно
  маркируются как строки. Это защищает и модель устройства, и остальные
  пользовательские значения в любых листах; отдельная обработка только `model`
  оставила бы ту же уязвимость в других столбцах.
- Отзыв сессий оформляется общей функцией сервиса с необязательным сохраняемым
  токеном. Сброс администратором вызывает её без исключения и удаляет все
  сессии цели; самостоятельная смена передаёт текущий cookie-токен и отзывает
  только остальные. Это предпочтительнее принудительного повторного входа
  после успешного self-service изменения пароля.
- Удаление строк сессий выполняется в транзакции `set_password`, чтобы смена
  пароля и отзыв доступа не могли разойтись при ошибке фиксации.

## Risks / Trade-offs

- [Текстовые значения могут выглядеть иначе, если клиент Excel прежде
  интерпретировал их как формулы] → это ожидаемое безопасное поведение; исходное
  содержимое сохраняется.
- [Текущий self-service cookie остаётся активным] → пользователь недавно
  подтвердил текущий пароль; все остальные сессии отзываются, а административный
  сброс отзывает их все без исключений.

## Migration Plan

Миграция БД не требуется. После выкладки новые пароли сразу аннулируют
указанные спеками сессии, а новые Excel-выгрузки будут содержать безопасные
текстовые ячейки. Откат кода не требует восстановления данных.

## MODIFIED Requirements

### Requirement: Сброс пароля администратором

Admin SHALL устанавливать сотруднику новый пароль без подтверждения старого;
пароль короче 8 символов MUST отклоняться. После успешного сброса система
SHALL отзывать все существующие сессии этого сотрудника.

#### Scenario: Админ сбрасывает пароль

- **WHEN** admin отправляет новый пароль от 8 символов
- **THEN** система сохраняет новый хеш, и сотрудник входит с новым паролем

#### Scenario: Отзыв сессий после сброса пароля

- **WHEN** admin успешно сбрасывает пароль сотрудника, у которого есть активные
  сессии
- **THEN** все существовавшие сессии сотрудника отклоняются при следующем
  запросе

#### Scenario: Слишком короткий пароль

- **WHEN** admin отправляет пароль короче 8 символов
- **THEN** система отвечает 422 `WEAK_PASSWORD` и не меняет пароль или сессии

#### Scenario: Обычный пользователь сбрасывает чужой пароль

- **WHEN** user вызывает сброс пароля другого сотрудника
- **THEN** система отвечает 403

#### Scenario: Сброс пароля неизвестному сотруднику

- **WHEN** admin сбрасывает пароль несуществующего пользователя
- **THEN** система отвечает 404 `USER_NOT_FOUND`

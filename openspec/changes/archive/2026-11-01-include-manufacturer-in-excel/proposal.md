# Proposal

## Why

В Excel-выгрузке модель устройства указана без производителя, поэтому модель
может быть неоднозначна для получателей отчёта. Добавление производителя
сделает выгрузку самодостаточной и упростит идентификацию устройств.

## What Changes

- Добавить колонку «Производитель» перед колонкой «Модель» на каждом листе
  Excel-выгрузки и заполнять её данными устройства.
- Не менять API-отчётов, фильтры, состав данных в БД и пользовательские
  интерфейсы.

## Capabilities

### New Capabilities

Не добавляются.

### Modified Capabilities

- `reports-export` — Excel-выгрузка включает производителя устройства перед
  моделью на всех листах с данными об устройствах.

## Impact

- Backend: формирование листов Excel и тесты выгрузки.
- API и схема БД не меняются: используется существующее поле производителя
  устройства.

# Proposal

## Why

Сейчас доступность backend можно проверить вручную через `/health`, но нет постоянного мониторинга и наглядной панели состояния. Gatus будет регулярно проверять API и БД, чтобы сбой было видно без входа в приложение.

## What Changes

- Добавить локальную конфигурацию Gatus с проверкой `GET /health`, HTTP-статуса и состояния БД.
- Добавить PowerShell-команду запуска Gatus и описать установку и использование в README.
- Панель Gatus будет доступна только на `localhost`; приложение и его API не меняются.

Вне scope: Docker-развёртывание, интеграция с каналами уведомлений, метрики приложения и изменение `/health`.

## Capabilities

### New Capabilities

- `service-monitoring`: локальный мониторинг доступности backend и БД через Gatus.

### Modified Capabilities

Нет.

## Impact

- Добавятся конфигурация и скрипт запуска Gatus в корне проекта.
- README получит инструкции для Windows и требование к Go для установки официального Gatus.
- Не затрагиваются backend/frontend код, API, БД и зависимости приложения.

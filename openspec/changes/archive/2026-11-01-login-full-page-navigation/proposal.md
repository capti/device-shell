# Proposal

## Why

После входа приложение сейчас меняет маршрут внутри SPA, сохраняя страницу
и её состояние. Полная загрузка целевого маршрута может очистить историю
Network в DevTools, если пользователь не включил Preserve log, но не скрывает
сам запрос или пароль во время передачи.

## What Changes

- После успешного входа выполнять полную навигацию к целевому внутреннему
  маршруту вместо перехода внутри SPA.
- Не менять протокол входа, обработку неверных данных или защиту credentials.

## Capabilities

### New Capabilities

Не добавляются.

### Modified Capabilities

- `frontend-shell` — успешный вход открывает целевой маршрут с полной загрузкой
  документа.

## Impact

- Frontend: страница входа.
- Backend API, схема БД и зависимости не меняются.
- DevTools контролируется браузером: изменение не гарантирует удаление записи
  Network, особенно при включённом Preserve log.

# Spec Delta

## MODIFIED Requirements

### Requirement: Агрегаты для графиков дашборда

Система SHALL отдавать пользователю с ролью admin агрегаты для графиков
дашборда одним запросом `GET /dashboard/charts`: динамику выдач и возвратов по
месяцам за последние 12 месяцев (включая текущий) и распределение
просроченных устройств по корзинам длительности 1–7, 8–14, 15–30 и 31+ дней.
Просрочка SHALL считаться единственной формулой из `services/device_state`.

#### Scenario: Динамика по месяцам

- **WHEN** за последние 12 месяцев происходили выдачи и возвраты
- **THEN** в `turnover` каждому месяцу периода соответствуют счётчики
  `checked_out` (по дате выдачи) и `returned` (по дате возврата), месяцы без
  событий присутствуют с нулями

#### Scenario: Корзины просрочки

- **WHEN** есть активные выдачи с просроченным сроком возврата
- **THEN** каждое такое устройство попадает ровно в одну корзину по полным
  дням просрочки, сумма корзин равна общему числу просроченных

#### Scenario: Просроченных нет

- **WHEN** активных просрочек нет
- **THEN** `overdue_buckets` отдаёт четыре корзины с нулями

#### Scenario: Неаутентифицированный запрос

- **WHEN** запрос приходит без сессии
- **THEN** система отвечает 401 и не считает агрегаты

#### Scenario: Запрос обычного пользователя

- **WHEN** пользователь с ролью user вызывает `GET /dashboard/charts`
- **THEN** система отвечает 403 и не считает агрегаты

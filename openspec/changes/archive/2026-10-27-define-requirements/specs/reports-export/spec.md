# Spec Delta

## Purpose

Даёт команде сводку о том, у кого находятся тестовые телефоны, и выгрузку для
менеджмента.

## ADDED Requirements

### Requirement: Сводка на дашборде

Дашборд SHALL показывать количество активных устройств, устройств у владельцев,
выданных, в ремонте, утерянных, архивных и просроченных.

#### Scenario: Открытие дашборда
- **WHEN** пользователь открывает дашборд
- **THEN** он видит актуальные счётчики по всем перечисленным категориям

### Requirement: Топ просрочек

Дашборд SHALL показывать до пяти устройств с самой давней просрочкой возврата.

#### Scenario: Просроченные устройства
- **WHEN** просрочено больше пяти устройств
- **THEN** на дашборде видны пять с наибольшей длительностью просрочки

### Requirement: Отчёт «у кого что»

Система SHALL формировать отчёт, показывающий владельца и текущего держателя
для каждого активного устройства.

#### Scenario: Просмотр отчёта
- **WHEN** пользователь открывает отчёт «у кого что»
- **THEN** каждая строка содержит устройство, владельца и держателя

### Requirement: Отчёт «просроченные»

Система SHALL формировать отчёт только по просроченным устройствам с датой
выдачи и сроком просрочки.

#### Scenario: Просмотр просрочек
- **WHEN** пользователь открывает отчёт «просроченные»
- **THEN** в отчёте только устройства, удовлетворяющие правилу просрочки

### Requirement: Экспорт в Excel

Система SHALL выгружать Excel-файл с листами «Все устройства», «Просроченные»
и «История выдач» за выбранный период.

#### Scenario: Успешная выгрузка
- **WHEN** пользователь нажимает «Экспорт»
- **THEN** скачивается файл `.xlsx` с тремя листами

### Requirement: Экспорт с учётом фильтров

Выгрузка SHALL учитывать активные фильтры списка устройств.

#### Scenario: Экспорт отфильтрованного списка
- **WHEN** пользователь выгружает список с фильтром «В ремонте»
- **THEN** в файле только устройства в ремонте

### Requirement: Единое правило просрочки в отчётах

Все отчёты и выгрузка SHALL использовать то же определение просрочки, что и
список устройств.

#### Scenario: Совпадение данных
- **WHEN** пользователь сравнивает список на экране и Excel
- **THEN** состав просроченных устройств совпадает

### Requirement: Доступ к отчётам

Просматривать отчёты и выгружать Excel SHALL любой аутентифицированный
пользователь.

#### Scenario: Выгрузка обычным пользователем
- **WHEN** user нажимает «Экспорт»
- **THEN** система формирует файл без ограничений по роли

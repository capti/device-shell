# Spec Delta

## ADDED Requirements

### Requirement: Фото в составе отчёта

Ответ со списком отчётов о состоянии SHALL включать для каждого отчёта его
приложенные фотографии (ссылки на оригинал и превью).

#### Scenario: Владелец видит фото отчёта
- **WHEN** владелец запрашивает отчёты о состоянии устройства
- **THEN** каждый отчёт содержит список приложенных к нему фотографий с URL

#### Scenario: Отчёт без фото
- **WHEN** к отчёту не прикладывали фотографий
- **THEN** список фото отчёта пуст

# Spec Delta

## ADDED Requirements

### Requirement: Отметка устройства как потерянного

Система SHALL переводить устройство из статуса `active` в `lost` по запросу
владельца или admin и MUST отклонять переход из любого другого статуса.

#### Scenario: Владелец отмечает утерю
- **WHEN** владелец переводит активное устройство в `lost`
- **THEN** статус становится `lost` и в истории появляется событие `status_changed`

#### Scenario: Недопустимый переход в lost
- **WHEN** устройство уже находится в статусе `lost` или `repair`, а приходит запрос на `lost`
- **THEN** система отвечает 409 `INVALID_STATUS_TRANSITION`

### Requirement: Возврат устройства из статуса lost

Система SHALL возвращать устройство из `lost` в `active` только по запросу
владельца или admin и MUST требовать непустой комментарий.

#### Scenario: Возврат из lost с комментарием
- **WHEN** владелец возвращает найденное устройство в `active` и пишет комментарий
- **THEN** статус становится `active`, а комментарий сохраняется в событии истории

#### Scenario: Возврат из lost без комментария
- **WHEN** запрос на возврат из `lost` не содержит комментария
- **THEN** система отвечает 422 `COMMENT_REQUIRED` и не меняет статус
